Urban Clamp is a microservices based **Household Services Platform**. Both the service providers and customers can use the platform. Service providers can add the services that they can provide. Admin role can manage the users and providers on the platform.

### About

- Designed and implemented a microservices architecture with Spring Boot, ensuring modularity and scalability.
- Developed a secure authentication system using JWT and OAuth2, with role-based access control.
- Integrated Kafka for event-driven communication between services, improving system reliability and responsiveness.
- Optimized performance with Redis caching, reducing database load and enhancing response times.
- Set up Prometheus and Grafana for real-time monitoring, tracking system health and performance metrics.
- Developed additional microservices in ASP.NET Core and Node.js, ensuring interoperability and efficient task handling.
- Deployed the platform on AWS with Docker, enabling containerized service management and scalability
